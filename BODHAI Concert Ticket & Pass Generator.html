DFD Level 0 — Context Level

External entities exchange with core BODHAI ticketing boundary

ENTITIES & DATAFLOWS:

  • Admin ➔ Event Details, Tier Pricing, Terms ➔ BODHAI
  • BODHAI ➔ Pass ID, Verifiable QR Payload ➔ Attendee
  • Turnstile Gate Operator ➔ Scanned QR / Pass ID ➔ BODHAI
  • BODHAI ➔ Check-in Authorization & Roster Update ➔ Gate

DFD Level 1 — Modular Processes

Functional subprocesses and localStorage data stores

PIPELINE PROCESSES:

  1. Process 1.0 Event Management: Saves to bodhai_events
  2. Process 2.0 Ticket Generation: Creates Ticket ID & QR
  3. Process 3.0 Pass Rendering: Applies theme matrix
  4. Process 4.0 Gate Verification: Updates bodhai_tickets status
  5. Process 5.0 Analytics Engine: Aggregates realtime ROI
